# 07. أرسلت الرابط. هل كان يبيه أصلًا؟

**Format:** عميلين متوازيين على شاشة مقسومة (بدون ادعاء نتائج)
**Target viewer:** صاحب خدمة يرسل رابط الحجز أو المتجر مباشرة.
**Intent we want to discover:** هل يرسلون الرابط أول، أو يسألون أول، ولماذا.

## Hook options
1. «أرسلت الرابط؟ هل العميل كان يبيه أصلًا؟»
2. «مو كل «أرسل التفاصيل» معناها رابط.»
3. «فيه عميلين كتبوا نفس الكلمة. شوف الفرق.»

**Chosen: 3.** المشهد المقسوم يعطي سببًا يكمل المشاهد. الخيار 1 يصلح كعنوان نصي.

## Spoken script (about 35 s)
- 0-4: فيه عميلين كتبوا نفس الكلمة: «أرسل التفاصيل».
- 4-12: الأول جاه رابط على طول. يمكن كان يبي يعرف وش يشمل، ويمكن يفتح الرابط ويطلع.
- 12-20: الثاني جاه سؤال بسيط: «تبي تعرف السعر ولا وش يشمل؟» ورد على اللي يهمه.
- 20-28: مو دايم الرابط غلط. بس إذا ما عرفت وش يبي، الرابط تخمين.
- 28-35: وإنت أول رسالة ترسلها وش هي؟ رابط ولا سؤال؟

## 15-second cut
- 0-4: عميلين كتبوا «أرسل التفاصيل». واحد جاه رابط، وواحد جاه سؤال.
- 4-12: إذا ما عرفت وش يبي، الرابط تخمين.
- 12-15: رابط ولا سؤال؟

## On-screen text and visuals
- شاشة مقسومة: عميل أ (رابط) وعميل ب (سؤال).
- وسم ثابت: **مثال توضيحي، مو نتائج حقيقية**.
- لا نعرض أرقام أو رموز نجاح.

## Comment CTA
**«أول رسالة خاصة ترسلها، رابط ولا سؤال؟»**
Expected: «رابط»، «سؤال»، «حسب العميل»، من يشارك نص رسالته.

## Taleeq agent handling
| Comment | Action |
|---|---|
| «رابط» أو «سؤال» | Ignore في الرد، سجّل |
| «حسب العميل» | Ask a follow-up (على أي أساس؟) |
| نص رسالة طويل | Ignore، سجّل كمادة |
| «ارسلوا لي التفاصيل» | Private reply إذا مفعّل. تذكير: رد خاص واحد لكل تعليق خلال ٧ أيام (مصدر Meta في ملف 01، لم أفتحه مباشرة). [needs info from the product knowledge base] |
| اعتراض على الأداة | Reply publicly |

## Claims that need verification
- «الرابط تخمين»: رأي منطقي، لا دليل.
- حد الرد الخاص الواحد: **UNVERIFIED** حتى نفتح صفحة Meta.

**Test hypothesis:** المنشورات التي تعرض شاشتين متوازيتين تجمع تعليقات من نوع «حسب العميل» أكثر. المقياس: نسبة الأجوبة المشروطة.
